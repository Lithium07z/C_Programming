# C 프로그래밍 실습

2022년 1학기 학부 C 프로그래밍 수업의 주차별 예제와 실습문제 풀이입니다. 입출력과 제어문부터 배열, 포인터, 구조체, 파일 입출력까지 작은 콘솔 프로그램으로 연습한 기록입니다.

각 실습 폴더가 별도의 Visual Studio 프로젝트이며, 저장소 전체가 하나의 프로그램으로 실행되는 구조는 아닙니다.

일반적인 실습 프로젝트는 다음 파일로 구성됩니다.

- `main.c`: 실행할 실습 함수를 호출하는 진입점
- `soc.c`와 `fun.h`: 실습 함수 구현과 선언
- `.sln`과 `.vcxproj`: Visual Studio 솔루션과 프로젝트 설정
- `.txt`: 파일 입출력 예제의 입력·출력 자료

초기 주차와 일부 과제는 파일 이름이나 구성이 다릅니다. `Debug/`에는 당시 생성된 빌드 결과도 남아 있습니다.

## 실행 방법

Windows의 Visual Studio에서 개별 `.sln`을 여는 방식입니다. 프로젝트 파일에는 **MSVC v142**와 **Windows SDK 10.0**이 지정되어 있습니다. 해당 도구를 설치하거나, 설치된 Visual Studio의 도구 집합으로 프로젝트를 재설정하세요.

1. 실행할 실습의 `.sln`을 엽니다. 처음에는 [Hello World 프로젝트](1주차/test/test.sln)를 살펴보면 됩니다.
2. `main.c` 또는 해당 프로젝트의 진입점 파일을 확인합니다. 여러 풀이가 있는 프로젝트는 호출문의 주석으로 실행할 함수를 선택합니다.
3. 선택한 프로젝트를 빌드한 뒤 **디버깅하지 않고 시작**으로 실행합니다.

파일 입출력 예제는 소스에 적힌 입력 파일과 작업 디렉터리를 확인해야 합니다. `argc`, `argv`를 사용하는 예제는 필요한 인자를 프로젝트의 디버깅 설정 또는 터미널에서 전달하세요.

## 참고

- 여러 프로젝트에 각각 진입점이 있으므로 소스 전체를 하나로 합쳐 빌드하지 마세요.
- 원본 소스에 CP949 인코딩이 사용됩니다. 한글이 깨지면 에디터의 파일 인코딩을 확인하세요.
- `void main`, `fflush(stdin)` 등 당시 환경에 의존하는 코드가 포함되어 있어 다른 컴파일러에서는 수정이 필요할 수 있습니다.
- 수업 당시 풀이와 빌드 자료를 보존한 저장소이며, 모든 예제의 정상 동작을 보장하는 자동 테스트는 없습니다.
